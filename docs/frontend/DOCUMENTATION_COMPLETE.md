## 🚀 الان چیکار کنم؟

### گزینه 1: شروع با Backend Integration (پیشنهادی)
```bash
# 1. بخون
cat START_HERE.md
cat BACKEND_INTEGRATION.md
cat IMPLEMENTATION_ROADMAP.md

# 2. نصب dependencies
npm install -D vitest @playwright/test
npm install ethers wagmi viem @rainbow-me/rainbowkit

# 3. شروع کن!
npm run dev
```

### گزینه 2: شروع با TDD
```bash
# 1. بخون
cat QUICK_START.md
cat DEVELOPMENT_PLAN.md

# 2. نصب testing tools
npm install -D vitest @vitest/ui @testing-library/svelte

# 3. اولین component رو بساز
# (مثلاً Button.svelte)
```
